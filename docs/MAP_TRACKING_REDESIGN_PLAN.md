# Map, tracking and reporting refinement

The user's page-based cascade supersedes the previous all-in-one selection panel. Stalls becomes the full cafeteria map; choosing an area opens an area map, choosing a stall opens its menu, and choosing an item opens its customisation page. Breadcrumbs restore parent context and browser Back works naturally. The AIDA Topic Explorer's selection/back pattern is design inspiration only; AIDA is not treated as a native APSpace component. Existing cart, pricing, stock, capacity, checkout and code services remain authoritative in this browser frontend.

Tracking reuses the existing route and state, with small components for status hero, explicit status progression, pickup details, existing QR controls, order breakdown and actual activity. All seven statuses and absent timestamps are handled without inventing events. Supplied illustration cards are copied locally and displayed through a clipped artwork window; baked-in text is not used as UI labels. Empty/closed/unavailable/loading/session/error contexts use the appropriate supplied asset.

More contains only modules outside the four primary taskbar entries for each role. Student activity becomes selectable pickup windows and readable per-stall capacity meters with plain-language availability. Admin charts gain interactive stall comparison and order-stage distribution, with filter links and underlying values. Reports use AIDA-inspired controls + document preview, typed report metadata and summary, styled PDF cover/contents/summary/table pages, and tabular CSV export from the same selected report. No AIDA source, data, backend, credentials or branding will be copied.

Reusable additions: WarmIllustration, MapJourneyBreadcrumbs, MapDiscovery, MenuDiscovery, ItemDiscovery, OrderTracking, TrackingProgress, PickupFacts, ReportBuilder, ReportPreview, AdminInsights. Geometry stays in the layout fixture; statuses and report calculations are tested as pure functions. Add desktop/mobile browser validation and regression tests for ordering, cancellation, expiry, code refresh and collection.
